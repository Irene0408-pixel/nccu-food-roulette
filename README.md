# 政大午晚餐救星｜美食大輪盤

## 專案結構

```text
nccu-food-roulette/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 使用方式

1. 用 VS Code 開啟 `nccu-food-roulette` 資料夾。
2. 直接用瀏覽器開啟 `index.html`。
3. 或在 VS Code 安裝 Live Server 後，右鍵 `index.html` → `Open with Live Server`。

## 已完成功能

- HTML5 Canvas 動態美食轉盤
- 依啟用店家數量自動切割扇形
- Ease-out 平滑減速動畫
- 指針＋中央 SPIN 按鈕
- 每次抽選消耗 1 次，共 5 次
- 5 次用完後，再點擊轉盤觸發「小7保底」Modal
- 新增店家
- 刪除店家
- 勾選／取消勾選店家
- LocalStorage 自動保存
- 恢復政大預設名單
- 清空名單
- RWD 手機／平板／桌機版
- 日系奶油、燕麥、莫蘭迪馬卡龍配色
- Toast 操作提示
